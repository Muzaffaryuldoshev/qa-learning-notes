# QA Learning Notes

Personal study notes covering QA theory — both manual testing foundations 
and automation concepts — built while learning QA and transitioning into 
QA automation engineering.

## Structure

### qa-manual/
Core manual testing concepts: SDLC/STLC, test levels & types, test design 
techniques, bug lifecycle, Agile/Scrum, test artifacts.

### qa-automation-concepts/
Automation-specific theory: what/how to automate, API testing fundamentals, 
non-functional testing, CI/CD, test metrics.
